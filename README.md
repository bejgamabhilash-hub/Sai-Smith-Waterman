# Sai Smith-Waterman

An interactive web-based tool for performing
Smith-Waterman Local Sequence Alignment.

## About the Project

This project demonstrates the Smith-Waterman
algorithm used to identify the best local alignment
between two DNA sequences.

## Features

- DNA sequence input
- Custom match, mismatch and gap scores
- Local alignment calculation
- Scoring matrix visualization
- Traceback path visualization
- Alignment score and results

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the website.
2. Enter two DNA sequences.
3. Set the scoring parameters.
4. Click Run Local Alignment.
5. View the alignment results and scoring matrix.
